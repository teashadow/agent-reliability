# ferret
> Threat model: the battery's shared memory — findings land here; arbiter and the exporters read from here.

MAD finding tracker with JSON storage and a Textual board.

## Commands

- `ferret new`
- `ferret list`
- `ferret show F-001`
- `ferret status F-001 reported`
- `ferret board`
- `ferret export F-001`

Alias command:

- `fo`
